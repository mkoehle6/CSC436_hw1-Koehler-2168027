1. RESOLUTION: Line 1, "Host www.burnscodev.com:443 was resolved," and line 4,
   "Trying 207.207.210.36:443..." show that DNS resolution succeeded and curl selected
   one of the returned IPv4 addresses.
2. TLS: Line 21, "* schannel: SSL/TLS connection renegotiated," shows that the TLS
   negotiation completed. This Schannel trace does not include the negotiated TLS version
   or cipher. The `-sS`, `-v`, and `-o` flags do not cause this curl build to display
   those values.
3. PROTOCOL: Line 9, "* using HTTP/1.x," identifies the HTTP protocol version. Line 6
   shows the client offering HTTP/1.1, and line 7 shows that the server accepted it.
